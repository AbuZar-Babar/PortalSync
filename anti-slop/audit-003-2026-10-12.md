# antislop Audit Report #003

- **Date:** 2026-10-12
- **Target:** FlowMind SaaS Dashboard Main Page (`apps/web/src/app/dashboard/page.tsx` and related dashboard layout components)
- **Audit Mode:** Mode 2 (AFTER: Numbered findings list with rule citations and priorities)
- **Active Dials:** ENERGY 1 / RHYTHM 2 / MOTION 2
- **Aesthetic Direction:** Dark Architectural Precision & Editorial Minimalism (FlowMind Design System / DESIGN.md)

---

## Executive Summary

The dashboard main overview page (`apps/web/src/app/dashboard/page.tsx`) was audited against the **38 Mandatory Antislop Rules (R-01 through R-38)** across all four delivery blocks.

While the underlying data plumbing, real-time Supabase subscriptions, and preflight modals function well, the UI retains legacy artifacts from earlier iterations:
1. **Em Dash Violations (R-02):** Em dashes (`—`) are used in duration calculation fallbacks and in 4 KPI card loading placeholders.
2. **Keyboard Accessibility (R-32):** Clickable run rows in the activity stream are plain `div` tags lacking `tabIndex`, keyboard activation (`Enter`/`Space`), and focus indicators.
3. **Contrast Deficits (R-25):** Small `text-slate-500` and `text-[10px] text-slate-400` on navy `#0c101d` surfaces fall below WCAG AA 4.5:1.
4. **Cartoon Mascot Inconsistency (R-22 & DESIGN.md):** The banner and loading screen render `RobotAvatar` cartoon mascot icons, contradicting the serious software instrument direction in `DESIGN.md`.
5. **Color & Styling Drift (R-01, R-13, R-20):** Deep navy `#0c101d` card backgrounds, cyan-to-indigo gradient buttons, and stacked neon glow shadows drift away from FlowMind's obsidian `#09090d` and stark white pill design tokens.

## Numbered Findings List

### Finding #1 [Priority: HIGH / Hard Gate] — R-02 (Copywriting: Em Dash)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (lines 76, 78, 80, 442, 467, 487, 512)
- **Violation:** Em dash character (`—`) used in `formatDuration` fallbacks and as loading placeholders in the 4 KPI metric cards.
- **Rule Violated:** R-02 (FORBIDDEN: em dash character `—` in any text).
- **Remediation:** Replace with `--` or a skeleton shimmer block (`animate-pulse`).

### Finding #2 [Priority: HIGH / Hard Gate] — R-32 (Keyboard Accessibility)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (line 721)
- **Violation:** Clickable run items in the Live Execution Stream are `div` elements with `onClick`, without `role="button"`, `tabIndex={0}`, Enter/Space key listeners, or visible focus indicators.
- **Rule Violated:** R-32 (REQUIRED: all interactive elements must be reachable and operable by keyboard with visible focus state).
- **Remediation:** Convert run items to keyboard-accessible interactive elements with `tabIndex={0}`, `role="button"`, `onKeyDown` handlers, and `focus-visible:ring-1 focus-visible:ring-white/40`.

### Finding #3 [Priority: HIGH / Hard Gate] — R-25 (Color Contrast)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (lines 514, 585, 592, 642, 654, 659)
- **Violation:** Micro-labels use `text-slate-500` and `text-[10px] text-slate-400` on `#0c101d` backgrounds, resulting in a contrast ratio below WCAG AA minimum 4.5:1.
- **Rule Violated:** R-25 (REQUIRED: all text must meet minimum WCAG AA contrast standard).
- **Remediation:** Upgrade secondary text to `text-zinc-300` / `text-zinc-400` and ensure all micro-labels meet at least 4.5:1 contrast against surface backgrounds.

### Finding #4 [Priority: HIGH / Hard Gate] — R-27 (UI States: Error Handling)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (lines 222-227)
- **Violation:** Data fetching errors are caught and logged silently via `console.error` without rendering an in-UI error banner or retry trigger for the user.
- **Rule Violated:** R-27 (REQUIRED: every UI that displays data must have empty, loading, and error states).
- **Remediation:** Add error state handling in UI with a dismissible error banner and a manual retry button.

### Finding #5 [Priority: HIGH / Hard Gate] — R-38 (Real Content vs Assumed Data)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (line 655)
- **Violation:** The Engine Platform widget displays a hardcoded string `"Windows 11 x64"` even when no runner is connected or when the runner is on another OS.
- **Rule Violated:** R-38 (FORBIDDEN: fabricating content that looks realistic without a real data source).
- **Remediation:** Display real connected runner platform information from `wf_runners` diagnostics, or show an honest placeholder like `Active Desktop Runner` / `Not Connected`.

### Finding #6 [Priority: MEDIUM / Purpose-Gate] — R-01 (Color & Gradients)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (lines 362, 403)
- **Violation:** Hero banner uses a blue-purple-navy gradient (`from-[#0c101d] via-[#11172e] to-[#0c101d]`), and "New Workflow" button uses a cyan-to-indigo gradient (`from-cyan-500 to-indigo-600`) without brand justification.
- **Rule Violated:** R-01 (FORBIDDEN as default without purpose: blue-to-purple / blue-to-cyan gradients as primary colors).
- **Remediation:** Align banner with FlowMind surface tokens (`#09090d` with hairline `border-white/10`) and style primary action buttons as high-contrast stark white pills (`bg-white text-zinc-950 font-bold hover:bg-zinc-200`).

### Finding #7 [Priority: MEDIUM / Purpose-Gate] — R-04 (Generic AI Glyphs)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (line 447)
- **Violation:** Active Workflows card renders `<Sparkles className="w-3 h-3" />` as a decorative badge icon.
- **Rule Violated:** R-04 (FORBIDDEN as default without purpose: Sparkle, Star, Magic as feature icons).
- **Remediation:** Replace generic sparkle icon with a purposeful status dot or workflow-relevant glyph.

### Finding #8 [Priority: MEDIUM / Purpose-Gate] — R-13 (Excessive Glow Shadows)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (lines 371, 387, 394, 403)
- **Violation:** Multiple simultaneous neon glow box-shadows (`shadow-[0_0_10px_rgba(0,240,255,0.15)]`, `shadow-[0_0_12px_rgba(0,240,255,0.15)]`, `shadow-[0_0_8px_#00f0ff]`, `shadow-cyan-500/20`) stacked across the header.
- **Rule Violated:** R-13 (Dose cap: glow forbidden on card + button + badge + icon simultaneously).
- **Remediation:** Remove redundant neon box-shadows; rely on clean hairline borders and subtle single-point focus indicators.

### Finding #9 [Priority: MEDIUM / Purpose-Gate] — R-22 (Cartoon Mascot Inconsistency)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (line 365) and `apps/web/src/app/dashboard/layout.tsx` (line 27)
- **Violation:** Renders `RobotAvatar` cartoon SVG mascot in the header banner and loading screen, contradicting `DESIGN.md` Section 1 ("No cartoon mascots... Serious, high-performance, calm, razor-sharp software instrument").
- **Rule Violated:** R-22 / R-37 (Visual identity alignment with DESIGN.md).
- **Remediation:** Replace cartoon robot with a clean typographic engine status indicator and pulse beacon matching FlowMind's architectural precision style.

### Finding #10 [Priority: LOW / Quality Lock] — R-16 (Marketing Buzzwords in App UI)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (lines 368, 372, 376)
- **Violation:** Banner uses theatrical copy: "Executive Command Center", `AUTONOMOUS` badge, and "zero-cloud-cost execution, and resilient self-healing selectors".
- **Rule Violated:** R-16 (FORBIDDEN: AI marketing buzzwords; use specific language that explains real benefits).
- **Remediation:** Simplify header copy to calm, functional operational language: "Operations Console", "Local Browser Replay", and clear status indicators.

### Finding #11 [Priority: LOW / Quality Lock] — R-20 (Visual Identity & Surface Tokens)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (entire file)
- **Violation:** Uses `#0c101d` (navy slate) surface color instead of FlowMind's canonical `#09090d` / `#0c0c0f` obsidian tokens from `DESIGN.md`.
- **Rule Violated:** R-20 (Design system token consistency).
- **Remediation:** Align card and panel surfaces with `#09090d` / `bg-[#09090d]/95` and hairline `border-white/10`.

### Finding #12 [Priority: LOW / Quality Lock] — R-11 (Border Radius Harmonization)
- **Location:** `apps/web/src/app/dashboard/page.tsx` (throughout interactive elements)
- **Violation:** Uncoordinated mix of `rounded-3xl` on banner, `rounded-2xl` on cards, `rounded-xl` on buttons, and `rounded-md` on badges.
- **Rule Violated:** R-11 (Use border radius consistent with the defined design system).
- **Remediation:** Standardize on `rounded-2xl` for structural containers, `rounded-xl` for inner cards, and `rounded-full` for CTA pills and status badges.
